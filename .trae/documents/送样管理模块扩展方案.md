# 送样管理模块扩展方案

## 背景

用户需要扩展现有的「Excel 计划导入」模块，使其支持新的 Excel 表头格式，并在网页上提供数据编辑和导出功能。

**可编辑字段**：QE决议是否送样、GPC决议是否送样、最终决议是否送样、需求数量备注、Q工单、箱号、送样日期、异常确认说明

## 一、数据模型扩展

**文件**: `backend/core/models.py`

在 `ProductionPlan` 模型中新增以下字段（需先检查是否已有该模型，若字段不匹配则重建）：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| month_str | CharField(20) | 月份（文本格式，如"2026-08"） |
| fab | CharField(50) | Fab |
| bu | CharField(50) | BU |
| customer_name | CharField(100) | 客户 |
| material_code_52 | CharField(100) | 52阶料号 |
| mode | CharField(50) | Mode |
| finished_product_code | CharField(100) | 成品料号 |
| next_month_mps | IntegerField | 下个月MPS数量 |
| next_next_month_mps | IntegerField | 下下个月MPS数量 |
| qe_decision | CharField(20) | QE决议是否送样 ⭐可编辑 |
| gpc_decision | CharField(20) | GPC决议是否送样 ⭐可编辑 |
| final_decision | CharField(20) | 最终决议是否送样 ⭐可编辑 |
| box_quantity | IntegerField | 每箱数量 |
| sample_request_qty | IntegerField | 需求送片量 |
| sample_remark | TextField | 需求数量备注 ⭐可编辑 |
| q_order | CharField(100) | Q工单 ⭐可编辑(ORT填写) |
| box_number | CharField(50) | 箱号 ⭐可编辑(ORT填写) |
| sample_date | DateField | 送样日期 ⭐可编辑(ORT填写) |
| exception_note | TextField | 异常确认说明 ⭐可编辑(ORT填写) |

> 注：由于现有 ProductionPlan 模型字段与需求差异较大，建议**删除旧模型重新创建**，或新建 `SamplePlan` 模型替代。

## 二、后端 API

**新建文件**: `backend/core/views/sample_plan_views.py`

### 2.1 API 接口列表

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/sample-plan/import/` | POST | Excel 导入 |
| `/api/sample-plan/list/` | GET | 数据列表（支持分页、筛选） |
| `/api/sample-plan/update/<id>/` | PUT | 更新单条记录（编辑可编辑字段） |
| `/api/sample-plan/export/` | POST | Excel 导出（支持筛选条件导出） |
| `/api/sample-plan/template/` | GET | 下载导入模板 |
| `/api/sample-plan/delete/<id>/` | DELETE | 删除单条记录 |

### 2.2 Excel 导入逻辑

- 使用 openpyxl 读取，按新的表头列名匹配
- 序号列自动生成，不导入
- 所有列按名称匹配，缺少非必填列时给默认值
- 可编辑字段导入时为空，后续在网页上填写

### 2.3 Excel 导出逻辑

- 使用 openpyxl 生成 .xlsx
- 导出全部字段，包含序号
- 支持按筛选条件导出（月份、Fab、客户等）

### 2.4 路由注册

**修改文件**: `backend/core/urls.py`

新增 sample-plan 相关路由。

## 三、前端页面

**改造文件**: `frontend/src/views/PlanImportView.vue`

### 3.1 页面结构

```
┌─────────────────────────────────────────────┐
│ 页面标题：送样管理                            │
├─────────────────────────────────────────────┤
│ [导入Excel] [导出Excel] [下载模板]            │
├─────────────────────────────────────────────┤
│ 筛选栏：月份 | Fab | 客户 | 搜索              │
├─────────────────────────────────────────────┤
│ 数据表格（可编辑）                            │
│ ┌───┬────┬───┬──┬────┬─────────┬──────────┐ │
│ │序号│月份│Fab│BU│客户│52阶料号 │Mode      │ │
│ ├───┼────┼───┼──┼────┼─────────┼──────────┤ │
│ │ 1 │08月│2A│..│..  │..       │..        │ │
│ │ 2 │08月│2B│..│..  │..       │..        │ │
│ └───┴────┴───┴──┴────┴─────────┴──────────┘ │
│ ← 横向滚动 →                                 │
├─────────────────────────────────────────────┤
│ 分页：共 XX 条  < 1 2 3 ... >                 │
└─────────────────────────────────────────────┘
```

### 3.2 表格功能

- **固定列**：序号（自动生成）
- **只读列**：月份、Fab、BU、客户、52阶料号、Mode、成品料号、下个月MPS数量、下下个月MPS数量、每箱数量、需求送片量
- **可编辑列**（点击单元格进入编辑模式）：
  - QE决议是否送样 → 下拉选择（是/否/待定）
  - GPC决议是否送样 → 下拉选择（是/否/待定）
  - 最终决议是否送样 → 下拉选择（是/否/待定）
  - 需求数量备注 → 文本输入
  - Q工单 → 文本输入
  - 箱号 → 文本输入
  - 送样日期 → 日期选择器
  - 异常确认说明 → 文本输入
- **操作列**：编辑（保存）、删除
- 表格支持横向滚动（列较多）

### 3.3 导出功能

- 导出按钮 → 调用后端导出 API
- 支持导出当前筛选结果
- 下载为 .xlsx 文件

### 3.4 前端 API

**修改文件**: `frontend/src/api/import.js`

新增 samplePlanApi 相关方法。

### 3.5 样式

- 沿用深蓝工业风设计（与现有页面一致）
- 可编辑单元格用不同背景色标识（浅蓝高亮）
- 表格使用 Element Plus 的 el-table 组件

## 四、实施步骤

### Step 1: 后端数据模型
1. 修改 `backend/core/models.py`，重建 ProductionPlan 或新建 SamplePlan
2. 执行 `python manage.py makemigrations` 和 `migrate`

### Step 2: 后端 API
1. 新建 `backend/core/views/sample_plan_views.py`
2. 实现导入、列表、更新、导出、模板下载、删除接口
3. 注册路由 `backend/core/urls.py`
4. 更新 `backend/core/views/__init__.py`

### Step 3: 前端 API 层
1. 修改 `frontend/src/api/import.js`，新增 samplePlanApi

### Step 4: 前端页面
1. 重写 `frontend/src/views/PlanImportView.vue`
2. 实现数据表格 + 内联编辑 + 导入导出

### Step 5: 验证
1. 启动后端 `python manage.py runserver`
2. 启动前端 `npm run dev`
3. 测试导入 → 编辑 → 导出完整流程

## 五、验证方式

1. 准备测试 Excel 文件（包含所有列）
2. 导入 → 检查数据是否正确入库
3. 在网页上编辑可编辑字段 → 保存 → 刷新验证持久化
4. 导出 Excel → 检查内容与网页一致
5. 筛选 → 导出筛选结果
